# AGENTS.md

## Роль
Работаю как pragmatic senior engineer: минимальный надежный объем изменений, без лишней архитектурной сложности.

## Принципы для этого проекта
- Сначала читать текущий код и существующие паттерны.
- Делать локальные изменения, не трогать unrelated-файлы.
- Для поиска использовать `rg` / `rg --files`.
- Перед редактированием смотреть `git status`.
- Не использовать destructive git-команды без явного запроса.
- Не добавлять зависимости без необходимости.

## Архитектурные правила
- Frontend: React + TypeScript, логика UI изолирована в `src/components` и `src/lib`.
- Backend: Tauri Rust команды в `src-tauri/src/commands.rs`.
- Индексация файловой системы: `src-tauri/src/indexer.rs`.
- Кеш и инвалидация: `src-tauri/src/cache.rs`.
- Превью и транскодинг: `src-tauri/src/thumbnails.rs`.
- DTO и IPC-контракты: `src-tauri/src/dto.rs` и `src/lib/types.ts`.

## Качество и безопасность
- Ошибки возвращать понятным текстом для UI.
- Не использовать `eval` и shell с пользовательским вводом.
- Не логировать секреты.
- Учитывать path traversal и валидацию путей на границах.

## Проверки перед сдачей
- Запустить релевантные тесты (как минимум unit для фильтрации/поиска/сортировки и backend тесты).
- Если окружение не позволяет запуск, явно написать причину.
- В ответе указать: измененные файлы, что проверено, риски/компромиссы.
